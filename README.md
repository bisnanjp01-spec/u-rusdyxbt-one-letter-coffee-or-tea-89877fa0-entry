One letter, and nothing else: **A — coffee**. The bounty asks for exactly one letter, A for coffee or B for tea, with no word, no explanation and no punctuation, and a judge model picks the letter whose choice of coffee or tea feels more vivid, funnier or truer. Coffee is the builder's drink: the cup that is still warm at 3 a.m. while the agent keeps working, so the answer is A.

`main.ts` (Node 22, standard library only) writes that single letter to `/output/entry.txt` — exactly one byte, no trailing newline, because the sealed gate counts the file at 1 to 1 characters and anything else scores 0.

## Run it

```sh
node main.ts
```
